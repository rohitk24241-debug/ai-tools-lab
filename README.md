AI Tools Lab

A Python project demonstrating basic sorting algorithms and utility functions as part of the Artificial Intelligence Tools and Applications Lab.

Project Description

This project contains:

- A Bubble Sort implementation
- Utility functions for checking palindromes
- Word counting
- Celsius to Fahrenheit conversion

The project demonstrates GitHub version control, branching, commits, pull requests, and AI-assisted development.

Installation

Clone the repository:

git clone https://github.com/rohitk24241-debug/ai-tools-lab.git

Move into the project directory:

cd ai-tools-lab

Make sure Python is installed:

python --version

Usage

Bubble Sort

Run the sorting program:

python sorting.py

Example:

numbers = [64, 34, 25, 12, 22, 11, 90]
print(bubble_sort(numbers))

Output:

[11, 12, 22, 25, 34, 64, 90]

Utility Functions

The "utils.py" module provides three functions:

from utils import is_palindrome, count_words, celsius_to_fahrenheit

print(is_palindrome("madam"))
print(count_words("Hello AI Tools Lab"))
print(celsius_to_fahrenheit(25))
